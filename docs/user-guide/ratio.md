# Ratio

The **Ratio** app (0) solves a proportion of the form `a:b = c:d` when
exactly one of the four terms is unknown.

## Opening the app

Open the home menu and select **Ratio**.

## Solving a proportion

Enter three of the four terms and leave the unknown one empty. Press
**Solve** to compute the missing term.

## Examples

| Ratio         | Missing term |
| ------------- | ------------ |
| `2 : 3 = 4 : ?` | 6            |
| `? : 3 = 4 : 6` | 2            |
| `2 : ? = 4 : 6` | 3            |
| `2 : 3 = ? : 6` | 4            |

## Errors

The app reports a clear error when:

- More than one term is left empty.
- No term is left empty.
- A term is zero or negative.
- A term is not a valid number.

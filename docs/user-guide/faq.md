# FAQ

## Is the calculator free?

Yes. The calculator is open source under the MIT license. See
[License](/project/license).

## Do I need an internet connection?

No. The calculator is a client-side application. Math evaluation happens in
the browser.

## Do I need a mouse?

No. The calculator is keyboard-first, and every feature is reachable from the
keyboard. See [Keyboard first usage](/getting-started/keyboard-first-usage).

## What is the difference between CAS and calculus?

CAS (Computer Algebra System) operations manipulate symbolic expressions:
simplify, expand, and differentiate. Calculus operations compute derivatives,
integrals, limits, Taylor series, summations, and products, either
symbolically or numerically. See the [CAS overview](/cas/overview) and
[Calculus overview](/calculus/overview).

## How do I get a fraction result?

Switch the numeric mode to **Fraction**. See
[Fractions](/user-guide/fractions).

## How do I use the previous answer?

Press `Ans` or type `ans`. The previous result is always available as the `ans`
variable. See [Variables](/user-guide/variables).

## Can I save values for later?

Yes. Save variables through the variables panel, or use the memory register.
See [Variables](/user-guide/variables) and [Memory](/user-guide/memory).

## Does the calculator support complex numbers?

Yes, when complex support is enabled in settings. See
[Complex numbers](/user-guide/complex-numbers).

## Why is `sin(30)` equal to `0.5` in one mode and something else in another?

Because of the angle mode. `sin(30)` equals `0.5` only in degree mode. See
[Angle modes](/user-guide/angle-modes).

## Where do the constants come from?

The constant catalog is defined in the repository and covers math, physics,
chemistry, and atomic data. See the
[scientific reference](/scientific-reference/constants-math).

## How do I report a bug?

See [Security and support](/project/support) for how to report issues.

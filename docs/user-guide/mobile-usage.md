# Mobile Usage

The calculator is usable on touch devices. The keypad layout adapts to remain touch-friendly while staying compact on desktop.

## Touch targets

Keypad buttons are sized for comfortable touch use on mobile. Button labels remain readable, and scientific functions stay easy to locate.

## No mouse required

The calculator does not require a mouse. On a touch device, tapping a button inserts the value and keeps the caret at the correct position.

## Keyboard access

When a hardware keyboard is available on a tablet, the keyboard-first features work as on desktop. See [Keyboard first usage](/getting-started/keyboard-first-usage).

## Responsive layout

- On desktop, the keypad remains compact.
- On mobile, the layout uses the available width and keeps touch targets comfortable.

## Caret behavior on touch

Tapping the expression editor positions the caret as expected. Tapping a keypad button keeps the caret at the correct logical position.

## Panels on mobile

Panels open as overlays and remain keyboard accessible. Opening a panel never destroys the current expression.

# Spacing

The design system uses a small, consistent spacing scale and a matching set of radii.

## Spacing tokens

| Token       | Value |
| ----------- | ----- |
| `--space-1` | 4px   |
| `--space-2` | 8px   |
| `--space-3` | 12px  |
| `--space-4` | 16px  |
| `--space-5` | 24px  |
| `--space-6` | 32px  |

## Radii tokens

| Token         | Value |
| ------------- | ----- |
| `--radius-sm` | 4px   |
| `--radius-md` | 6px   |
| `--radius-lg` | 8px   |

## Focus ring width

| Token                | Value |
| -------------------- | ----- |
| `--focus-ring-width` | 2px   |

## Usage principles

- Prefer the spacing scale over ad hoc values.
- Keypad gutters use the compact end of the scale.
- Panels and dialogs use the larger end.
- Radii stay small and calm; no pill-shaped controls.

# Changelog

All notable changes to the calculator are documented on this page.

## 0.1.0

Initial release. The first production-minded version with:

- Expression-based entry with cursor editing, selection, and smart delete.
- Broad scientific function catalog.
- Angle modes: DEG, RAD, GON.
- Numeric modes: STANDARD, EXACT_DECIMAL, FRACTION, BIGINT with feature
  detection and fallback.
- Configurable complex number support.
- Scientific constant catalog.
- User variables with persistence.
- Classic memory register.
- Persistent history in IndexedDB.
- Light, dark, and system themes.
- Enableable CAS-style operations: simplify, expand, differentiate.
- Calculus operations: derivatives, integrals, limits, Taylor series,
  summations, products.
- Full keyboard navigation and accessible React Aria controls.
- An isolated VitePress documentation hub.

## Unreleased

- Expression editor UX parity refinements.
- Cursor placement services and tests.

## Reporting bugs

Report bugs through the project's issue tracker. Include:

- The steps to reproduce.
- The expected and actual behavior.
- The browser and version.
- Any error messages shown.

## Feature requests

Suggest features through the issue tracker. Explain the use case and how it
aligns with the project goals. See [Roadmap](/project/roadmap).

## Security issues

Report security issues privately. See [Security](/project/security).

# Function Catalog

This page catalogs every scientific function supported by the calculator, grouped by category. Functions are typed by name, for example `sin(30)`.

## Trigonometric functions

| Function | Description         |
| -------- | ------------------- |
| `sin(x)` | Sine of an angle    |
| `cos(x)` | Cosine of an angle  |
| `tan(x)` | Tangent of an angle |

## Inverse trigonometric functions

| Function  | Description     |
| --------- | --------------- |
| `asin(x)` | Inverse sine    |
| `acos(x)` | Inverse cosine  |
| `atan(x)` | Inverse tangent |

## Hyperbolic functions

| Function  | Description        |
| --------- | ------------------ |
| `sinh(x)` | Hyperbolic sine    |
| `cosh(x)` | Hyperbolic cosine  |
| `tanh(x)` | Hyperbolic tangent |

## Inverse hyperbolic functions

| Function   | Description                |
| ---------- | -------------------------- |
| `asinh(x)` | Inverse hyperbolic sine    |
| `acosh(x)` | Inverse hyperbolic cosine  |
| `atanh(x)` | Inverse hyperbolic tangent |

## Logarithmic and exponential functions

| Function   | Description                               |
| ---------- | ----------------------------------------- |
| `ln(x)`    | Natural logarithm                         |
| `log(x)`   | Common logarithm with a configurable base |
| `log10(x)` | Base ten logarithm                        |
| `log2(x)`  | Base two logarithm                        |
| `exp(x)`   | Exponential function                      |

## Power and root functions

| Function        | Description           |
| --------------- | --------------------- |
| `sqrt(x)`       | Square root           |
| `cbrt(x)`       | Cube root             |
| `nthRoot(x, n)` | Nth root of a value   |
| `square(x)`     | Square of a value     |
| `cube(x)`       | Cube of a value       |
| `pow(x, y)`     | Exponentiation        |
| `inv(x)`        | Reciprocal of a value |

## Rounding functions

| Function   | Description                                       |
| ---------- | ------------------------------------------------- |
| `abs(x)`   | Absolute value                                    |
| `sign(x)`  | Sign of a value                                   |
| `floor(x)` | Greatest integer less than or equal to a value    |
| `ceil(x)`  | Smallest integer greater than or equal to a value |
| `round(x)` | Rounds a value to a given precision               |
| `trunc(x)` | Truncates a value toward zero                     |

## Arithmetic functions

| Function         | Description                 |
| ---------------- | --------------------------- |
| `min(a, b, ...)` | Minimum of a list of values |
| `max(a, b, ...)` | Maximum of a list of values |
| `gcd(a, b, ...)` | Greatest common divisor     |
| `lcm(a, b, ...)` | Least common multiple       |
| `mod(a, b)`      | Remainder of a division     |
| `factorial(n)`   | Factorial of an integer     |
| `percent(x)`     | Percent of a value          |

## Operators

The core keypad also exposes operators: `+`, `-`, `*`, `/`, `^`, `!`, `%`, and the argument separator `,`. See [Operator precedence](/user-guide/operator-precedence).

## Examples

$$
\sin(30^\circ) = \frac{1}{2}
$$

$$
\ln(e) = 1
$$

$$
\sqrt{16} = 4
$$

$$
\gcd(12, 18) = 6
$$
